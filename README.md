# RU-HEPE Assignment Template

Reusable assignment template for RU-HEPE courses.

## Purpose
This repository provides a consistent structure for course assignments, student submissions, assessment criteria, evidence, and automated validation.

## Suggested structure
- `assignment.md` — assignment brief
- `submission/` — student submission area
- `rubric/` — assessment rubric
- `evidence/` — supporting evidence
- `.github/workflows/validate-submission.yml` — automated structure check

## Governance
Evidence-First / No Fabrication. Automated checks support workflow quality only; final academic assessment remains a human decision.
