# RU-HEPE Assignment Template

Reusable assignment template for RU-HEPE courses and the HED3505 GitHub Learning Hub.

## Canonical learning flow

**Activity → Evidence → Submission → Feedback → Portfolio**

## Purpose

This repository provides a consistent structure for:
- assignment instructions;
- student submission artifacts;
- required evidence;
- reflection;
- assessment criteria;
- feedback;
- optional structural validation.

## Suggested structure

- `assignment.md` — assignment brief
- `STATUS.md` — workflow state only
- `EVIDENCE-REQUIREMENTS.md` — required evidence
- `REFLECTION.md` — student reflection prompt/record
- `FEEDBACK.md` — instructor feedback record
- `submission/` — student submission area
- `rubric/` — assessment rubric
- `evidence/` — supporting evidence
- `.github/workflows/validate-submission.yml` — optional automated structure check

## Workflow states

`NOT_STARTED → IN_PROGRESS → SUBMITTED → REVIEWED → REVISION_REQUESTED → COMPLETE`

These are workflow states only. They are **not grades**.

## Governance

Evidence-First / No Fabrication. Automated checks support workflow quality only; final academic assessment remains a human decision.

Student-specific work should be private by default. Do not store sensitive student, health, grade, or confidential school information in a public repository.
